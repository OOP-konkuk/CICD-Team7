## Overview

SSD와 SD는 1:1 대응합니다. `:System` 블랙박스 내부를 Domain Model의 설계 클래스들로 분해합니다.

| SSD (OOA) | SD (OOD) | System Operation |
|-----------|----------|-----------------|
| SSD-1 | SD-1 | `onTick()` |
| SSD-2 | SD-2 | `onFrontDetected()` — 좌/우 열린 경우 |
| SSD-3 | SD-3 | `onFrontDetected()` — 전/좌/우 모두 막힌 경우 |
| SSD-4 | SD-4 | `onDustDetected(val)` |

---

## SD-1: Perform Cleaning

> **SSD-1 → SD-1**: `onTick()` 호출 시 `:System` 내부에서 FrontSensor 확인 후 전진/청소 명령.  
> UC-1 Typical Course: Tick → 센서 확인(전/좌/우 False) → Forward → On

### PlantUML Code

```plantuml
@startuml SD1_PerformCleaning
title SD-1: Perform Cleaning\n(based on SSD-1: onTick())

participant ":DigitalClock" as Clock
participant ":RVCOrchestrator" as Orch
participant ":FrontSensor" as FS
participant ":LeftSensor" as LS
participant ":RightSensor" as RS
participant ":MotorController" as Motor
participant ":CleanerController" as Cleaner

Clock -> Orch : onTick()
activate Orch
Orch -> FS : detect()
activate FS
FS --> Orch : false
deactivate FS
Orch -> LS : detect()
activate LS
LS --> Orch : false
deactivate LS
Orch -> RS : detect()
activate RS
RS --> Orch : false
deactivate RS
note right of Orch : [No obstacle — proceed forward]
Orch -> Motor : setDirection(FORWARD)
Orch -> Cleaner : setMode(ON)
deactivate Orch
@enduml
```

## SD-2: Avoid Front Obstacle

> **SSD-2 → SD-2**: `onFrontDetected()` 호출 시 청소 중단 → 열린 방향으로 회전 → 전진 → 청소 재개.  
> UC-2 Pre-Req: 좌 또는 우 중 하나는 열려있음.

### PlantUML Code

```plantuml
@startuml SD2_AvoidFrontObstacle
title SD-2: Avoid Front Obstacle\n(based on SSD-2: onFrontDetected())

participant ":FrontSensor\n(Interrupt)" as FS
participant ":RVCOrchestrator" as Orch
participant ":LeftSensor" as LS
participant ":MotorController" as Motor
participant ":CleanerController" as Cleaner

FS -> Orch : onFrontDetected()
activate Orch
Orch -> Cleaner : setMode(OFF)
Orch -> LS : detect()
activate LS
LS --> Orch : false
deactivate LS
note right of Orch : [Left open → turn LEFT]
Orch -> Motor : setDirection(LEFT)
Orch -> Motor : setDirection(FORWARD)
Orch -> Cleaner : setMode(ON)
deactivate Orch
@enduml
```

## SD-3: Avoid All Obstacles

> **SSD-3 → SD-3**: `onFrontDetected()` 호출 후 `:System` 내부의 `checkLeftSensor()` / `checkRightSensor()` 자기 호출을  
> `LeftSensor.detect()` / `RightSensor.detect()` 직접 호출로 구체화.  
> UC-3 Pre-Req: Front/Left/Right Sensor 모두 True → 후진 후 방향 전환.

### PlantUML Code

```plantuml
@startuml SD3_AvoidAllObstacles
title SD-3: Avoid All Obstacles\n(based on SSD-3: onFrontDetected(), all blocked)

participant ":FrontSensor\n(Interrupt)" as FS
participant ":RVCOrchestrator" as Orch
participant ":LeftSensor\n(Periodic)" as LS
participant ":RightSensor\n(Periodic)" as RS
participant ":MotorController" as Motor
participant ":CleanerController" as Cleaner

FS -> Orch : onFrontDetected()
activate Orch
Orch -> LS : detect()
activate LS
LS --> Orch : true
deactivate LS
Orch -> RS : detect()
activate RS
RS --> Orch : true
deactivate RS
note right of Orch
  SSD-3: checkLeftSensor() = True
          checkRightSensor() = True
  → 전/좌/우 모두 막힘
end note
Orch -> Cleaner : setMode(OFF)
Orch -> Motor : setDirection(BACKWARD)
Orch -> Motor : setDirection(LEFT or RIGHT)
Orch -> Motor : setDirection(FORWARD)
Orch -> Cleaner : setMode(ON)
deactivate Orch
@enduml
```

## SD-4: Power Up Cleaning

> **SSD-4 → SD-4**: `onDustDetected()` 호출 시 청소 파워업 후 일정 시간 경과 후 ON 복귀.  
> UC-4 Typical Course: Dust Sensor(True, Periodic) → Clean Up → 일정 시간 후 On.

### PlantUML Code

```plantuml
@startuml SD4_PowerUpCleaning
title SD-4: Power Up Cleaning\n(based on SSD-4: onDustDetected())

participant ":DustSensor\n(Periodic)" as DS
participant ":RVCOrchestrator" as Orch
participant ":CleanerController" as Cleaner

DS -> Orch : onDustDetected(val: bool)
activate Orch
note right of Orch : val = true
Orch -> Cleaner : setMode(UP)
note right of Cleaner : 내부 타이머 시작 (boostEndTime 설정)

loop until update() == true
  Orch -> Cleaner : update()
  activate Cleaner
  Cleaner --> Orch : false (아직 진행 중)
  deactivate Cleaner
end

Orch -> Cleaner : update()
activate Cleaner
Cleaner --> Orch : true (boost 만료)
deactivate Cleaner

Orch -> Cleaner : setMode(ON)
deactivate Orch
@enduml
```

| SSD (OOA) | SD (OOD) | `:System` 블랙박스 분해 |
|-----------|----------|------------------------|
| SSD-1: `onTick()` | SD-1 | RVCOrchestrator, FrontSensor, LeftSensor, RightSensor, MotorController, CleanerController |
| SSD-2: `onFrontDetected()` | SD-2 | RVCOrchestrator, LeftSensor, MotorController, CleanerController |
| SSD-3: `onFrontDetected()` all blocked | SD-3 | RVCOrchestrator, LeftSensor, RightSensor, MotorController, CleanerController |
| SSD-4: `onDustDetected()` | SD-4 | RVCOrchestrator, CleanerController |
