# /sdd — SDD 유지보수 (오른쪽 센서 삭제 반영)

> **정책 (CLAUDE.md 2·6·7절)**
> 설계를 재도출하지 않는다. `legacy/docs/sdd/SDD.md`의 클래스 구조·이름·계층·시퀀스를 **그대로 유지**하고, 오른쪽 센서 삭제가 강제하는 부분(센서 의존성·회피 시퀀스·시그니처)만 수정한다.
> PDF·`CICD-Team7-main/`·`objective.md`는 열람 금지. 수정한 SDD는 legacy 대비 **변경/일치**를 명시한다.

## 0. 로그 시작

```bash
TS=$(date +%Y-%m-%d_%H%M)
echo "# /sdd" > log/${TS}_sdd.md
echo "" >> log/${TS}_sdd.md
echo "## 사용 프롬프트" >> log/${TS}_sdd.md
echo "\`/sdd\`" >> log/${TS}_sdd.md
```

## 1. 입력 (이외 자료 보지 말 것)

- `legacy/docs/sdd/SDD.md` — 기준선 SDD (인계 대상)
- `docs/srs/SRS.md` — 방금 수정된 SRS (상위 진실)
- `docs/maintenance/impact.md` — SDD 계층 변경 스코프

`docs/specs/`·`reference/`의 PDF·CICD·objective.md는 열람 금지.

## 2. 작업 — 인계 후 최소 수정

1. `legacy/docs/sdd/SDD.md`를 `docs/sdd/SDD.md`로 인계한다.
2. 수정된 SRS와 `impact.md`가 지목한 부분만 고친다. 전형적 대상:
   - **추상화 인터페이스**: 근접 센서 인터페이스가 방향 비특정(예: `isBlocked()`)이면 **인터페이스 자체는 일치**, 변경 없음. 방향이 박힌 시그니처/멤버만 조정.
   - **컴포넌트 설계**: 회피 경로 결정 컴포넌트의 의존성에서 우측 센서 참조 제거, 공개 메서드 시그니처에서 우측 센서 인자 제거.
   - **시퀀스 다이어그램**: 회피 시퀀스에서 우측 센서 조회·우회전 분기 삭제 (좌측 가능 → 좌회전, 아니면 후진으로 단순화).
   - **디렉토리·파일 매핑 / 추적성 매트릭스**: 사라진 의존성 반영. 파일 분할 구조는 **그대로 유지**.
3. 클래스명·인터페이스명·계층은 **legacy 그대로**. 이름을 새로 짓거나 컴포넌트를 재분해하지 않는다.

## 3. 차이 표기 (필수)

`docs/sdd/SDD.md` 말미에 변경 이력 표:

| 컴포넌트/다이어그램/시그니처 | legacy 대비 | 내용 |
|---|---|---|
| 회피 경로 컴포넌트 ctor | 변경 | 우측 센서 의존성 인자 제거 |
| 근접 센서 추상화 인터페이스 | 일치 | 방향 비특정이라 변경 없음 |
| 회피 시퀀스 다이어그램 | 변경 | 우회전 분기 삭제 |
| 계층 구조 | 일치 | legacy와 동일 |
| ... | ... | ... |

## 4. 자기 점검

- [ ] legacy의 클래스·인터페이스·계층·디렉토리 구조를 보존했는가? (재설계하지 않았는가?)
- [ ] 우측 센서 의존성·시그니처·시퀀스 분기가 일관되게 제거됐는가?
- [ ] 방향 비특정 추상화처럼 변경 불필요한 항목을 "일치"로 명시했는가?
- [ ] 시그니처가 C++ 코드블록으로 정확히 적혀 `/code`가 그대로 받아쓸 수 있는가?
- [ ] PDF·CICD·objective.md를 열지 않았는가?

## 5. 로그 종료

`log/${TS}_sdd.md`에 채움:
- `## 주요 결정`: 어떤 컴포넌트/시그니처/시퀀스를 수정했는지, 무엇을 의도적으로 보존했는지(특히 추상화 인터페이스 일치 여부)
- `## 생성·수정 파일`: `docs/sdd/SDD.md`
- `## 차이 표기`: legacy 대비 변경 N건 / 일치 M건
- `## 결과 요약`: 변경 컴포넌트 수, 수정 시그니처 수, 다이어그램 변경 수
- `## 검증 방법`: `wsl bash -lc "diff -u legacy/docs/sdd/SDD.md docs/sdd/SDD.md | head -100"`
- `## 다음 단계`: `/code`
